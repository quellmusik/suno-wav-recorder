lib/wav-encoder.js

A synthetic 1-second 440 Hz tone goes through every part of the encoder: the header bytes, the 16-bit and 24-bit interleaving, the round trip back to float, saturation, and the streaming accumulator's chunk boundaries. Everything is synchronous so the whole run finishes before the load event, which is what makes it checkable from brave --headless --dump-dom.

Open test/wav-encoder.test.html?emit=1 and the page also prints the encoded 16-bit file as base64, so it can be written to disk and played.
