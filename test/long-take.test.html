30-minute take

Pushes 30 minutes of 48 kHz stereo through WavAccumulator exactly the way the worklet feeds it (8192-frame chunks), then finishes the file and reports the JS heap at its peak, the size of the Blob, and how long it took. It also decodes the 1-second synthetic WAV that is already on disk, which is the playability check: the browser's own decoder either accepts that file or does not.

Run it with test/run-tests.ps1, or open this page through test/serve.ps1.
