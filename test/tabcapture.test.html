Tab capture, end to end

This page is an extension page, so it can call chrome.tabCapture. It opens test/tabcapture/tone.html as a real tab playing 440 Hz, takes a stream id for that tab, starts the real offscreen.html recorder on it, records four seconds, stops it, and then decodes the WAV the recorder produced.

Nothing here reimplements the recorder: the audio path is offscreen.js, recorder-worklet.js and lib/wav-encoder.js, the same three files the extension ships. The only substitute is the tab being recorded.
